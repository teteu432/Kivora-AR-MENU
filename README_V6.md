# Kivora AR Menu V6 — Cartão manual 8x5 cm

Esta versão troca a detecção de superfície por rastreamento de um cartão manual.

- Cartão físico usado: 8 cm × 5 cm
- Lado menor (5 cm) é a referência principal do marcador
- Hambúrguer alvo: 13 cm de largura
- Relação aproximada: 13 / 5 = 2,6×

## Como testar
1. Hospede o projeto em HTTPS (ex.: Vercel).
2. Abra pelo Chrome no celular.
3. Toque em "Ver na minha mesa".
4. Mostre o cartão manual para a câmera.
5. Mantenha o cartão inteiro visível; o alimento deve aparecer preso ao lado dele.

## Observação
AR.js pattern marker funciona melhor quando o marcador real se parece com o padrão usado no .patt. Esta versão foi ajustada para o cartão manual criado nesta conversa.
