# Kivora AR Menu

Protótipo de cardápio 3D com suporte a Realidade Aumentada.

## Rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testar no celular

Para acesso local:

```bash
npm run dev -- --host
```

Para testar AR de forma confiável, publique na Vercel e abra a URL HTTPS no celular.
